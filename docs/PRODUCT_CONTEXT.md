# Backend Product Context

Atlas backend powers ESG data collection, evidence extraction, normalization, and reporting workflows.

## Backend product responsibilities
- Enforce tenant-aware access and data boundaries.
- Execute extraction and template generation flows.
- Persist and serve metrics/reporting data.
- Provide auditable operation traces.

## Product priorities
- Accuracy and trust in extracted data.
- Stable automation pipelines.
- API compatibility for frontend and external consumers.
